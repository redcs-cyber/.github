# Examples

## AI Ecosystem PHP CLI

`ai_ecosystem.php` is a self-contained PHP CLI example that prints a comprehensive AI ecosystem map.
It includes:

- Core AI technologies such as transformer architectures, machine learning, deep learning, NLP, and computer vision.
- Infrastructure components such as cloud computing, data storage, processing power, APIs, and microservices.
- Tools and platforms such as TensorFlow, PyTorch, and Hugging Face.
- Application domains such as healthcare, autonomous vehicles, and finance.
- Capability, dependency, and governance notes for every component.
- Text, JSON, and health-summary output formats.
- Built-in validation that reports `Validation errors: 0` and exits with code `0` when the example is complete.

Run it with:

```bash
php examples/ai_ecosystem.php
php examples/ai_ecosystem.php --format=json
php examples/ai_ecosystem.php --format=summary
php examples/ai_ecosystem.php --validate
php examples/ai_ecosystem.php --help
```
